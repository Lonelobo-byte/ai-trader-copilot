# AI Trader Copilot — premium product direction

Create a premium institutional market-intelligence product, not a generic
crypto exchange. Retain the product's dark foundation and Inter/JetBrains Mono
typography. Use the existing blue, purple, green, red, and restrained gold
semantic accents; do not add pink gradients, serif display type, or noisy
consumer trading visuals.

## Experience principles

- Make the dashboard feel like a calm, high-trust analyst workstation: strong
  data hierarchy, generous spacing, clear status, and reduced visual noise.
- Make login feel private and credible: one focused card, product value proof,
  calm security cues, and a visual route to account creation.
- Make plans feel premium and understandable: 3–4 comparison cards, a clear
  recommended tier, transparent cadence/pricing, and provider security proof.
- Payment success is a verified processing state, never an instant entitlement.

## Visual rules

- Background `#0c0d14`; primary panels around `#151621`; use low-opacity
  blue/purple ambient glow only as depth, never as a large gradient canvas.
- Use blue for navigation/primary actions, green for live/verified status,
  gold sparingly for the featured annual tier, and red only for risk/errors.
- Use 12–16px card radius, fine `rgba(255,255,255,.05)` borders, 8px spacing
  rhythm, compact mono labels, and clean Inter display text.
- Preserve desktop analyst density while keeping login and plans mobile-first.
